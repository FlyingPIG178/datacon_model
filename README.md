# YL-analysis 代码分析工具

一个基于LLM（大语言模型）的智能代码分析工具，用于自动化检测代码中的潜在漏洞和安全问题。

## 功能特点

- 自动化代码分析：支持对项目代码进行自动化的漏洞检测
- 多种漏洞类型检测：
  - 任意文件访问
  - 认证绕过
  - 缓冲区溢出
  - 命令注入
  - 整数溢出
  - 其他通用漏洞
- 可配置的分析设置：支持自定义API地址、模型参数、分析深度等
- 并行处理：支持多线程并行分析以提高效率
- 结果可视化：提供分析结果的可视化展示

## 技术栈

- 后端：Python + aiohttp
- 前端：Vue.js + Element Plus
- AI模型：支持与GPT-3.5等大语言模型集成

## 安装部署

1. 安装依赖：
```bash
pip install -r requirements.txt
```

2. 启动服务：
```bash
python server.py
```

## 使用指南

1. 项目管理：
   - 上传或选择要分析的项目代码
   - 支持管理多个项目

2. 分析配置：
   - 设置分析深度和超时时间
   - 配置并行处理参数
   - 选择需要检测的漏洞类型

3. 运行分析：
   - 选择目标项目启动分析
   - 实时查看分析进度
   - 获取详细的分析报告
