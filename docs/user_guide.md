# YL-analysis 使用指南

## 概述

YL-analysis 是一个基于大语言模型的代码漏洞分析工具，能够自动检测代码中的潜在安全问题，并提供详细的分析报告。本文档提供了 YL-analysis 的详细使用指南，包括界面操作、功能说明和最佳实践。

## 快速入门

### 登录系统

1. 打开浏览器，访问 YL-analysis 系统地址（默认为 `http://localhost:8080`）
2. 系统不需要登录，直接进入主界面

### 主界面概览

YL-analysis 的主界面由以下几个部分组成：

- **顶部导航栏**：包含系统标题和主要功能区域切换按钮
- **左侧菜单**：包含项目管理、分析管理、设置等功能入口
- **主内容区**：显示当前功能的详细内容
- **底部状态栏**：显示系统状态、版本信息等

## 项目管理

### 查看项目列表

1. 在左侧菜单中点击「项目管理」
2. 系统将显示所有已上传的项目列表
3. 列表中包含项目名称、上传时间、文件大小等信息

### 上传新项目

1. 在项目列表页面，点击「上传项目」按钮
2. 在弹出的对话框中，点击「选择文件」或将文件拖拽到指定区域
3. 选择要上传的项目 ZIP 文件
4. 可以选择性地修改项目名称（默认使用 ZIP 文件名）
5. 点击「上传」按钮开始上传
6. 上传完成后，项目将出现在项目列表中

#### 项目文件要求

- 文件格式必须是 ZIP 压缩文件
- 文件大小不超过 10MB
- ZIP 文件内应包含完整的项目代码
- 支持的编程语言：Python, Java, JavaScript, PHP, C/C++, Go 等

### 查看项目详情

1. 在项目列表中，点击项目名称或「查看」按钮
2. 系统将显示项目的详细信息，包括：
   - 项目基本信息（名称、大小、上传时间等）
   - 文件列表
   - 文件内容预览

### 删除项目

1. 在项目列表中，找到要删除的项目
2. 点击该项目行右侧的「删除」按钮
3. 在弹出的确认对话框中，点击「确认」按钮
4. 项目将被永久删除（此操作不可撤销）

## 代码分析

### 启动分析任务

1. 在左侧菜单中点击「代码分析」
2. 在分析页面，选择要分析的项目
3. 选择漏洞类型（可多选）
4. 可选：启用「应急模式」（分析速度更快，但可能降低准确性）
5. 点击「开始分析」按钮
6. 系统将创建分析任务并加入队列

### 支持的漏洞类型

YL-analysis 支持检测多种常见的代码安全漏洞，包括：

- **SQL 注入**：检测不安全的 SQL 查询构造
- **跨站脚本 (XSS)**：检测未经过滤的用户输入输出到 HTML
- **命令注入**：检测不安全的系统命令执行
- **路径遍历**：检测不安全的文件路径处理
- **不安全的反序列化**：检测不安全的数据反序列化
- **XML 外部实体注入 (XXE)**：检测不安全的 XML 解析
- **服务器端请求伪造 (SSRF)**：检测不安全的 URL 请求
- **不安全的直接对象引用 (IDOR)**：检测缺少访问控制的对象引用
- **敏感信息泄露**：检测代码中的敏感信息
- **缺少函数级访问控制**：检测缺少权限验证的敏感功能

### 查看分析状态

1. 在「代码分析」页面，可以看到当前正在执行的分析任务和队列中的任务
2. 对于正在执行的任务，系统会显示：
   - 项目名称
   - 漏洞类型
   - 分析进度
   - 已用时间
   - 实时日志

### 查看分析结果

1. 分析完成后，系统会自动显示分析结果
2. 也可以在「分析历史」中查看历史分析结果
3. 分析结果包括：
   - 漏洞摘要（数量、类型、风险级别分布）
   - 漏洞详情列表
   - 每个漏洞的详细信息

### 漏洞详情

点击漏洞列表中的某个漏洞，可以查看其详细信息：

- **漏洞描述**：漏洞的详细描述
- **风险级别**：高、中、低
- **漏洞链**：导致漏洞的函数调用链
- **代码片段**：相关的代码片段，高亮显示漏洞点
- **修复建议**：修复漏洞的建议和示例代码

### 导出分析报告

1. 在分析结果页面，点击「导出报告」按钮
2. 选择报告格式（PDF、HTML 或 JSON）
3. 点击「确认」按钮
4. 系统将生成报告文件并提供下载

## 分析队列管理

### 查看队列状态

1. 在左侧菜单中点击「分析队列」
2. 系统将显示当前队列状态，包括：
   - 当前正在执行的任务
   - 队列中等待的任务
   - 历史任务

### 停止分析任务

1. 在「分析队列」页面，找到正在执行的任务
2. 点击「停止」按钮
3. 在弹出的确认对话框中，点击「确认」按钮
4. 系统将停止当前任务，并开始执行队列中的下一个任务（如果有）

### 清空分析队列

1. 在「分析队列」页面，点击「清空队列」按钮
2. 在弹出的确认对话框中，点击「确认」按钮
3. 系统将清空队列中的所有等待任务（不影响当前正在执行的任务）

## 系统设置

### 查看系统设置

1. 在左侧菜单中点击「设置」
2. 系统将显示当前的系统设置

### 修改 LLM 设置

1. 在「设置」页面，找到「LLM 设置」部分
2. 可以修改以下设置：
   - LLM 提供商（OpenAI、Anthropic、本地模型等）
   - 模型选择（GPT-3.5、GPT-4、Claude 等）
   - 温度参数（控制输出的随机性）
   - API 密钥（如果需要更新）
3. 修改完成后，点击「保存」按钮

### 修改分析设置

1. 在「设置」页面，找到「分析设置」部分
2. 可以修改以下设置：
   - 最大文件大小
   - 最大文件数量
   - 分析超时时间
   - 是否启用应急模式
3. 修改完成后，点击「保存」按钮

### 修改系统设置

1. 在「设置」页面，找到「系统设置」部分
2. 可以修改以下设置：
   - 日志级别
   - 最大队列大小
   - 项目目录
   - 日志目录
3. 修改完成后，点击「保存」按钮

### 重置设置

1. 在「设置」页面，点击「重置为默认值」按钮
2. 在弹出的确认对话框中，点击「确认」按钮
3. 系统将重置所有设置为默认值

## 实时日志

### 查看实时日志

1. 在左侧菜单中点击「日志」
2. 系统将显示实时日志流
3. 日志包括系统日志和分析任务日志

### 过滤日志

1. 在「日志」页面，使用顶部的过滤选项
2. 可以按以下条件过滤日志：
   - 日志级别（DEBUG、INFO、WARNING、ERROR、CRITICAL）
   - 日志来源（系统、分析任务等）
   - 关键词搜索

### 清空日志显示

1. 在「日志」页面，点击「清空」按钮
2. 日志显示区域将被清空（不影响日志文件）

## 最佳实践

### 项目准备

为了获得最佳的分析结果，建议按照以下方式准备项目：

1. **完整性**：确保项目包含所有必要的源代码文件
2. **依赖**：包含项目的依赖信息（如 requirements.txt, package.json 等）
3. **结构**：保持原始的项目目录结构
4. **大小**：移除不必要的大文件（如二进制文件、图片等）
5. **注释**：保留代码注释，有助于 LLM 理解代码

### 漏洞类型选择

根据项目类型选择合适的漏洞类型：

1. **Web 应用**：SQL 注入、XSS、CSRF、SSRF、路径遍历
2. **API 服务**：认证绕过、权限控制、数据泄露
3. **桌面应用**：不安全的文件操作、命令注入
4. **移动应用**：不安全的数据存储、不安全的通信

### 分析结果解读

1. **优先处理高风险漏洞**：先关注风险级别为「高」的漏洞
2. **验证漏洞**：根据漏洞描述和代码片段，验证漏洞是否真实存在
3. **理解漏洞链**：了解漏洞的传播路径，有助于全面修复
4. **参考修复建议**：根据系统提供的修复建议进行修复

### 性能优化

1. **应急模式**：对于大型项目，可以启用应急模式加快分析速度
2. **选择性分析**：只选择与项目相关的漏洞类型
3. **分批分析**：将大型项目分成多个小项目进行分析
4. **优化项目大小**：移除不必要的文件，减小项目大小

## 常见问题

### 分析任务长时间无响应

**问题**：分析任务启动后长时间没有进度更新。

**解决方案**：
- 检查网络连接是否正常
- 检查 LLM API 服务是否可用
- 尝试停止当前任务并重新启动
- 启用应急模式减少分析时间
- 检查项目大小，可能项目过大导致分析缓慢

### 分析结果不准确

**问题**：分析结果中包含误报或漏报。

**解决方案**：
- 尝试使用更强大的 LLM 模型（如 GPT-4 代替 GPT-3.5）
- 调整 LLM 温度参数（降低温度可能提高准确性）
- 禁用应急模式，获取更详细的分析
- 确保项目代码完整，包含所有必要的文件

### 上传项目失败

**问题**：无法上传项目 ZIP 文件。

**解决方案**：
- 检查 ZIP 文件大小是否超过限制（默认 10MB）
- 确保 ZIP 文件格式正确
- 尝试使用不同的浏览器
- 检查网络连接是否正常

### WebSocket 连接断开

**问题**：实时日志或分析状态更新中断。

**解决方案**：
- 刷新页面重新建立连接
- 检查网络连接是否正常
- 检查浏览器是否支持 WebSocket
- 如果使用代理或 VPN，可能需要调整设置

## 高级功能

### 自定义漏洞类型

高级用户可以通过修改配置文件添加自定义漏洞类型：

1. 在 `main/prompt_templates` 目录下创建新的提示词模板
2. 在 `config.json` 中添加新的漏洞类型定义
3. 重启系统使更改生效

### API 集成

YL-analysis 提供 RESTful API，可以与其他系统集成：

1. API 基础路径：`/api`
2. 主要 API 端点：
   - `/api/challenges`：项目管理
   - `/api/analysis/start`：启动分析
   - `/api/analysis/status`：获取分析状态
   - `/api/analysis/results/{task_id}`：获取分析结果

详细的 API 文档请参考 [API 接口文档](api/api_interface.md)。

### 批量分析

对于需要批量分析多个项目的场景，可以使用以下方法：

1. 使用 API 接口编写脚本，自动上传项目并启动分析
2. 将多个小项目合并为一个大项目进行分析
3. 使用命令行工具批量处理（需要单独安装，请参考高级文档）

## 总结

YL-analysis 是一个功能强大的代码漏洞分析工具，通过结合大语言模型和静态代码分析技术，能够有效识别代码中的潜在安全问题。本文档提供了详细的使用指南，包括界面操作、功能说明和最佳实践，帮助用户充分利用 YL-analysis 的功能，提高代码的安全性。

如果您在使用过程中遇到任何问题，请参考常见问题部分，或者联系系统管理员获取帮助。
