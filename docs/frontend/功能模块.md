# YL-analysis安全分析前端功能模块

## 1. 概览模块

### 功能描述

概览模块是系统的首页，提供项目整体情况的可视化展示，包括漏洞统计、文件分析情况、漏洞类型分布等信息，帮助用户快速了解系统状态和分析结果。

### 实现细节

- **文件路径**：`src/views/DashBoard.vue`
- **主要组件**：
  - 统计卡片：显示关键指标
  - 图表组件：使用ECharts展示漏洞分布和趋势
  - 数据表格：展示关键漏洞和最近扫描

### 数据来源

- 漏洞统计数据：通过API从后端获取
- 图表数据：基于漏洞分析结果生成
- 最近扫描记录：从后端获取历史扫描记录

### 交互功能

- 点击"分析更多"按钮：跳转到漏洞分析页面
- 点击"查看详情"按钮：查看特定漏洞或扫描的详细信息

## 2. 项目管理模块

### 功能描述

项目管理模块负责管理待分析的代码项目，支持项目上传、删除、查看和分析操作，是用户进行漏洞分析的入口。

### 实现细节

- **文件路径**：`src/views/project-management.vue`
- **主要组件**：
  - 项目表格：`src/components/project/ProjectTable.vue`
  - 上传对话框：`src/components/project/UploadDialog.vue`
  - 分析对话框：`src/components/project/AnalysisDialog.vue`

### 核心功能

#### 项目列表

- 展示所有已上传的项目
- 显示项目名称、创建时间等信息
- 提供分析和删除操作

#### 项目上传

- 支持选择本地文件夹上传
- 自动处理文件上传过程
- 显示上传进度和结果

#### 项目分析

- 选择漏洞类型进行分析
- 启动分析任务
- 显示分析状态和进度

### API接口

- `listChallenges()`：获取项目列表
- `deleteProject(projectName)`：删除指定项目
- `uploadFolder(formData)`：上传项目文件夹
- `startAnalysis(projectName, vulType)`：开始分析项目

## 3. 漏洞分析模块

### 功能描述

漏洞分析模块是系统的核心功能，通过调用图可视化展示函数调用关系，并提供漏洞详情查看、节点信息展示等功能，帮助用户理解漏洞的传播路径和影响范围。

### 实现细节

- **文件路径**：`src/views/call-graph.vue`
- **主要组件**：
  - 图形查看器：`src/components/call-graph/GraphViewer.vue`
  - 节点详情：`src/components/call-graph/NodeDetails.vue`

### 核心功能

#### 调用图可视化

- 使用vis-network库实现交互式网络图
- 支持节点拖拽、缩放、选择等操作
- 不同类型节点使用不同颜色标识（源函数、汇函数、普通函数）

#### 节点详情展示

- 显示选中节点的详细信息
- 展示节点的入度和出度关系
- 提供漏洞分析结果查看

#### 漏洞信息展示

- 显示漏洞类型、威胁评分、利用方式等信息
- 提供修复建议和分析理由
- 展示污点参数和污点操作

### 数据结构

调用图数据结构：
```javascript
{
  nodes: [
    { id: 1, label: 'function_name', type: 'source|sink|normal', ... },
    // 更多节点
  ],
  edges: [
    { from: 1, to: 2, ... },
    // 更多边
  ]
}
```

漏洞分析数据结构：
```javascript
{
  vulnerability_analysis: {
    存在漏洞: true,
    漏洞类型: 'SQL注入',
    威胁评分: 8,
    漏洞函数: 'execute_query',
    利用方式: '...',
    修复建议: '...',
    分析理由: '...'
  },
  taint_params: ['user_input', ...],
  taint_actions: ['...']
}
```

### API接口

- `getCallGraph(projectName)`：获取项目调用图数据

## 4. 设置模块

### 功能描述

设置模块允许用户配置系统参数，包括LLM服务设置、API密钥、分析参数等，为漏洞分析提供必要的配置支持。

### 实现细节

- **文件路径**：`src/views/settings.vue`
- **主要组件**：
  - 设置表单：`src/components/settings/SettingsForm.vue`

### 可配置项

- **测试模式**：启用/禁用测试模式
- **重试次数**：设置API调用失败时的重试次数
- **超时设置**：设置API调用超时时间
- **OpenAI API密钥**：设置用于LLM服务的API密钥
- **OpenAI API基础URL**：设置API服务的基础URL
- **模型名称**：设置使用的LLM模型名称

### 数据验证

- 重试次数：必须在1-20之间
- 超时设置：必须在1-3600秒之间
- 模型名称：不能为空

### API接口

- `getSettings()`：获取当前设置
- `saveSettings(settings)`：保存设置

## 5. 日志模块

### 功能描述

日志模块负责收集、展示和管理系统日志，包括分析过程中的信息、警告和错误，帮助用户了解系统运行状态和排查问题。

### 实现细节

- **文件路径**：`src/components/layout/LogPanel.vue`
- **状态管理**：`src/stores/logStore.js`

### 核心功能

#### 日志收集

- 收集不同级别的日志（信息、警告、错误、调试）
- 记录日志时间戳和内容
- 限制日志数量，避免内存占用过大

#### 日志展示

- 可隐藏/显示的日志面板
- 支持按日志级别过滤
- 自动滚动到最新日志

#### 日志管理

- 清空日志
- 导出日志到文件
- 错误日志通知

### 状态管理

使用Pinia管理日志状态：

```javascript
state: () => ({
  logs: [],
  logPanelVisible: false,
  logFilter: 'all',
  maxLogCount: 1000,
  notifyOnError: true,
})
```

主要操作：

- `addLog(message, type, timestamp)`：添加日志
- `clearLogs()`：清空日志
- `toggleLogPanel()`：切换日志面板显示状态
- `exportLogs()`：导出日志到文件

## 6. 布局模块

### 功能描述

布局模块负责整体页面结构的组织和管理，包括侧边栏、顶部栏、主内容区和日志面板等，为其他功能模块提供统一的布局框架。

- **主要组件**：

  - 顶部栏：`src/components/layout/Header.vue`
  - 任务状态栏：`src/components/layout/TaskStatusBar.vue`
  - 日志面板：`src/components/layout/LogPanel.vue`

### 布局结构


## 7. API模块

### 功能描述

API模块负责前端与后端的通信，封装了所有与后端交互的接口，为其他模块提供数据服务。

### 实现细节

- **文件路径**：`src/components/api.js`
- **使用技术**：axios

### 主要接口

#### 项目管理接口

- `listChallenges()`：获取项目列表
- `deleteProject(projectName)`：删除项目
- `uploadFolder(formData)`：上传文件夹

#### 分析接口

- `getVulTypes()`：获取支持的漏洞类型
- `startAnalysis(projectName, vulType)`：开始分析
- `stopAnalysis()`：停止分析
- `getAnalysisStatus()`：获取分析状态
- `getAnalysisResults(projectName)`：获取分析结果

#### 调用图接口

- `getCallGraph(projectName)`：获取调用图数据

#### 设置接口

- `getSettings()`：获取设置
- `saveSettings(settings)`：保存设置

#### 提示词接口

- `getPrompts()`：获取提示词列表
- `getPrompt(promptName)`：获取提示词内容
- `savePrompt(promptName, content, format)`：保存提示词
- `createPrompt(name, content, category, format)`：创建提示词

### 请求/响应处理

- **请求拦截器**：统一处理请求头、认证等
- **响应拦截器**：统一处理响应格式、错误等
- **错误处理**：统一处理网络错误、服务器错误等
