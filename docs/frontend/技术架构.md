# YL-analysis安全分析前端技术架构

## 技术选型

### Vue3框架

项目选择Vue3作为核心框架，主要基于以下考虑：

- **Composition API**：提供更灵活的代码组织方式，使逻辑复用更加简单
- **更好的TypeScript支持**：Vue3从底层重写，提供了更好的类型推断
- **更小的包体积**：通过tree-shaking优化，减少了运行时体积
- **更好的性能**：虚拟DOM重写，渲染性能显著提升

### Vite构建工具

选择Vite作为构建工具，主要优势：

- **极速的冷启动**：基于ESM的开发服务器，无需打包即可启动
- **快速的热更新**：HMR速度极快，提升开发效率
- **优化的构建**：基于Rollup的生产构建，输出高度优化的静态资源

### Element Plus组件库

选择Element Plus作为UI组件库，主要考虑：

- **丰富的组件**：提供了大量开箱即用的组件，加速开发
- **暗色主题支持**：符合项目的UI设计需求
- **与Vue3完美集成**：专为Vue3设计，API一致性好
- **高度可定制**：支持主题定制，可以满足特定的设计需求

### Pinia状态管理

选择Pinia替代Vuex，主要优势：

- **更简洁的API**：无需mutations，actions可以是异步的
- **更好的TypeScript支持**：完整的类型推断
- **更小的体积**：比Vuex更轻量
- **Vue DevTools集成**：提供良好的调试体验

### 可视化技术

- **ECharts**：用于数据图表展示，如漏洞类型分布、趋势等
- **vis-network**：用于调用链的网络图可视化，支持交互式操作
- **highlight.js**：用于代码语法高亮，提升代码查看体验

## 架构设计

### 整体架构

项目采用前后端分离架构，前端负责UI展示和用户交互，后端提供API服务。

```
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│   浏览器    │ <──> │  前端应用   │ <──> │  后端API    │
└─────────────┘      └─────────────┘      └─────────────┘
```

### 前端架构

前端采用组件化、模块化的设计思路，主要分为以下几层：

1. **视图层(Views)**：页面级组件，对应路由
2. **组件层(Components)**：可复用的UI组件
3. **状态层(Stores)**：全局状态管理
4. **服务层(API)**：与后端通信的接口封装
5. **工具层(Utils)**：通用工具函数

```
┌─────────────────────────────────────────────────────┐
│                      视图层(Views)                   │
├─────────────────────────────────────────────────────┤
│                      组件层(Components)              │
├───────────────┬─────────────────────┬───────────────┤
│   状态层      │      服务层         │    工具层      │
│  (Stores)     │      (API)         │   (Utils)     │
└───────────────┴─────────────────────┴───────────────┘
```

### 模块划分

项目按功能模块划分，主要包括：

1. **核心布局模块**：负责整体页面布局
   - 侧边栏导航
   - 顶部控制栏
   - 日志面板

2. **项目管理模块**：负责项目的CRUD操作
   - 项目列表
   - 项目上传
   - 项目删除

3. **漏洞分析模块**：负责展示漏洞分析结果
   - 调用图可视化
   - 节点详情展示
   - 漏洞信息展示

4. **设置模块**：负责系统配置
   - LLM服务配置
   - API密钥管理
   - 分析参数设置

### 状态管理

使用Pinia进行状态管理，主要store包括：

1. **logStore**：管理日志信息
   - 日志记录
   - 日志过滤
   - 日志导出

2. **projectStore**：管理项目信息(未实现，目前通过API直接获取)
   - 项目列表
   - 当前选中项目

3. **settingsStore**：管理系统设置(未实现，目前通过API直接获取和保存)
   - LLM服务配置
   - 分析参数

### 路由设计

采用Vue Router管理路由，主要路由包括：

- `/dashboard` - 概览页面
- `/projects` - 项目管理页面
- `/call-graph` - 调用图分析页面
- `/settings` - 系统设置页面

所有路由共享同一个布局组件，通过嵌套路由实现。

### API设计

前端通过封装的API模块与后端通信，主要使用axios库，包括：

- 请求拦截器：处理请求头、认证等
- 响应拦截器：统一处理响应格式、错误等
- API函数：按功能模块封装各个接口

## 响应式设计

项目采用响应式设计，主要通过以下方式实现：

1. **Vue3响应式系统**：使用ref、reactive等API管理组件状态
2. **Element Plus栅格系统**：使用el-row、el-col组件实现响应式布局
3. **CSS媒体查询**：针对不同屏幕尺寸调整样式

## 性能优化

项目采取了多种性能优化措施：

1. **组件懒加载**：路由组件使用动态导入，按需加载
2. **虚拟滚动**：大数据列表使用虚拟滚动技术
3. **缓存策略**：对API响应进行适当缓存
4. **按需导入**：第三方库按需导入，减少包体积

## 安全考虑

前端安全措施包括：

1. **输入验证**：对用户输入进行验证
2. **敏感信息处理**：API密钥等敏感信息使用密码框显示
3. **CSRF防护**：API请求添加适当的头部
