## 系统简介

YL-analysis是一款基于大语言模型的代码安全分析系统，旨在帮助开发人员和安全团队快速识别、分析和修复代码中的安全漏洞。系统通过静态代码分析和调用图分析，能够检测多种常见的安全漏洞，如SQL注入、跨站脚本攻击、路径遍历等，并提供详细的漏洞分析报告和修复建议。

## 技术栈

前端部分基于Vue3和Element Plus开发，选择这些技术的原因如下：

- **Vue3**：提供更好的性能、更小的包体积、Composition API支持、更好的TypeScript集成以及改进的响应式系统
- **Element Plus**：提供丰富的UI组件，设计美观，使用简单，文档完善，社区活跃，能够快速构建专业的用户界面
- **Pinia**：Vue官方推荐的状态管理库，比Vuex更轻量、更直观，提供更好的TypeScript支持
- **Vue Router**：Vue官方路由管理器，支持嵌套路由、动态路由、路由守卫等功能

## 系统结构

系统整体分为4个主要页面：

- **概览**：展示漏洞统计、扫描历史等内容，提供系统整体状态的快速视图
- **项目管理**：负责项目的上传、删除、添加扫描任务等操作，是系统的核心功能入口
- **漏洞分析**：展示项目的漏洞分析结果，包括漏洞详情、修复建议、调用链等内容，通过可视化图形展示函数调用关系
- **设置**：提供大语言模型API密钥设置、扫描参数配置等系统设置功能

系统采用模块化和组件化开发方式，每个页面都是一个独立的模块，不同功能之间解耦，提高代码复用性和开发效率。
