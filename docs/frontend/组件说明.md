# YL-analysis安全分析前端组件说明

## 视图组件 (Views)

视图组件是页面级别的组件，对应路由配置中的各个页面。

### DashBoard.vue

**路径**: `src/views/DashBoard.vue`

**功能**: 系统概览页面，展示漏洞统计、分析文件数量、漏洞修复率等关键指标，以及漏洞类型分布、漏洞趋势图表和关键漏洞列表。

**主要特点**:
- 使用统计卡片展示关键指标
- 使用ECharts图表展示漏洞分布和趋势
- 展示关键漏洞和最近扫描记录

### project-management.vue

**路径**: `src/views/project-management.vue`

**功能**: 项目管理页面，用于管理待分析的代码项目，支持项目上传、删除和分析操作。

**主要特点**:
- 展示项目列表
- 提供项目上传功能
- 支持项目删除和分析操作
- 集成上传对话框和分析对话框组件

### call-graph.vue

**路径**: `src/views/call-graph.vue`

**功能**: 调用图分析页面，通过可视化图形展示函数调用关系，并提供节点详情查看功能。

**主要特点**:
- 项目选择和调用图切换
- 使用Splitpanes实现分割面板布局
- 左侧展示调用图，右侧展示节点详情
- 支持节点点击、边点击等交互操作

### settings.vue

**路径**: `src/views/settings.vue`

**功能**: 系统设置页面，用于配置LLM服务参数、API密钥等系统设置。

**主要特点**:
- 展示设置表单
- 支持设置保存和重置
- 处理设置加载和错误状态

## 布局组件 (Layout)

布局组件负责整体页面结构的组织和管理。

### PageLayout.vue

**路径**: `src/components/PageLayout.vue`

**功能**: 主布局组件，组织整个应用的页面结构，包括侧边栏、顶部栏、主内容区和日志面板。

**主要特点**:
- 使用Element Plus的Container组件实现布局
- 集成侧边栏、顶部栏、任务状态栏和日志面板
- 管理分析状态和日志状态
- 实现响应式布局

### SideBar.vue

**路径**: `src/components/layout/SideBar.vue`

**功能**: 侧边栏组件，提供应用的主导航菜单。

**主要特点**:
- 展示应用logo和标题
- 提供导航菜单，包括概览、项目管理、漏洞分析和设置
- 支持路由导航和高亮当前路由

### Header.vue

**路径**: `src/components/layout/Header.vue`

**功能**: 顶部栏组件，提供全局操作和状态展示。

**主要特点**:
- 展示当前页面标题
- 提供全局操作按钮，如显示/隐藏日志面板
- 展示用户信息和系统状态

### LogPanel.vue

**路径**: `src/components/layout/LogPanel.vue`

**功能**: 日志面板组件，展示系统日志和分析过程信息。

**主要特点**:
- 可隐藏/显示的面板设计
- 支持按日志类型过滤（全部、错误、警告、信息、调试）
- 提供日志清空和导出功能
- 支持自动滚动到最新日志
- 使用不同颜色区分不同类型的日志

### TaskStatusBar.vue

**路径**: `src/components/layout/TaskStatusBar.vue`

**功能**: 任务状态栏组件，展示当前分析任务的状态和进度。

**主要特点**:
- 展示任务状态（等待中、运行中、已完成、失败）
- 显示进度条和百分比
- 提供取消任务按钮
- 支持状态变化的动画效果

## 调用图组件 (Call Graph)

调用图组件负责函数调用关系的可视化展示和交互。

### GraphViewer.vue

**路径**: `src/components/call-graph/GraphViewer.vue`

**功能**: 调用图可视化组件，使用vis-network库实现交互式网络图。

**主要特点**:
- 展示函数调用关系图
- 支持节点拖拽、缩放、选择等交互操作
- 提供缩放控制按钮
- 自定义节点和边的样式
- 处理节点点击和边点击事件

### NodeDetails.vue

**路径**: `src/components/call-graph/NodeDetails.vue`

**功能**: 节点详情组件，展示选中节点的详细信息和漏洞分析结果。

**主要特点**:
- 使用标签页分离不同类型的信息（漏洞分析、节点详情、统计信息）
- 展示漏洞信息，包括威胁评分、漏洞函数、利用方式、修复建议等
- 显示节点基本信息，如ID、类型等
- 展示节点的入度和出度关系
- 使用ECharts展示统计图表

## 项目组件 (Project)

项目组件负责项目管理相关功能。

### ProjectTable.vue

**路径**: `src/components/project/ProjectTable.vue`

**功能**: 项目表格组件，展示项目列表和操作按钮。

**主要特点**:

- 显示项目名称、创建时间等信息
- 提供分析和删除操作按钮
- 处理空状态和加载状态

### UploadDialog.vue

**路径**: `src/components/project/UploadDialog.vue`

**功能**: 上传对话框组件，用于上传项目文件夹。

**主要特点**:
- 使用Element Plus的Dialog组件实现对话框
- 提供项目名称输入
- 支持选择本地文件夹上传
- 显示已选择的文件夹名称
- 处理上传状态和进度

### AnalysisDialog.vue

**路径**: `src/components/project/AnalysisDialog.vue`

**功能**: 分析对话框组件，用于配置和启动项目分析。

**主要特点**:
- 显示项目名称
- 提供漏洞类型选择
- 支持启动分析操作
- 处理分析状态和进度
