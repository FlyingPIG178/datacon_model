# YL-analysis安全分析前端项目概述

## 项目简介

YL-analysis安全分析前端是一个基于Vue3开发的Web应用，旨在为安全分析工具提供直观、易用的可视化界面。该项目主要用于展示代码安全漏洞分析结果，包括漏洞详情、调用链分析、代码查看等功能，帮助开发人员和安全分析师更好地理解和修复代码中的安全问题。

## 技术栈

项目采用现代前端技术栈开发：

- **核心框架**：Vue 3 (Composition API)
- **构建工具**：Vite
- **UI组件库**：Element Plus
- **状态管理**：Pinia
- **路由管理**：Vue Router
- **图表可视化**：ECharts
- **网络可视化**：vis-network
- **代码高亮**：highlight.js
- **面板分割**：Splitpanes

## 主要功能

项目提供以下核心功能：

1. **项目管理**：上传、删除和管理待分析的代码项目
2. **漏洞分析**：展示不同类型的安全漏洞，提供摘要和详细视图
3. **调用链分析**：可视化展示函数调用关系，帮助理解漏洞传播路径
4. **代码查看**：支持查看和高亮显示漏洞相关代码
5. **日志管理**：实时展示分析过程的日志信息
6. **系统设置**：配置LLM服务链接、API密钥、提示词模板等

## 项目结构

项目采用模块化开发，主要分为以下几个部分：

- **视图(views)**：主要页面组件，包括概览、项目管理、漏洞分析和设置
- **组件(components)**：可复用的UI组件，如调用图、表单、卡片等
- **API**：与后端通信的接口封装
- **状态管理(stores)**：使用Pinia管理应用状态
- **路由(router)**：页面导航配置
- **样式(assets)**：全局样式和资源文件

## 界面设计

界面采用暗色主题，具有科技感的设计，主要包括：

1. 左侧导航栏：用于切换不同功能页面
2. 顶部控制栏：显示当前项目和操作选项
3. 主内容区：展示具体功能内容
4. 可隐藏的日志面板：显示系统日志和分析进度

## 后端集成

前端通过RESTful API与后端服务通信，主要接口包括：

- 项目管理相关接口
- 漏洞分析相关接口
- 调用图数据接口
- 文件内容获取接口
- 系统设置相关接口

## 部署方式

项目支持多种部署方式：

1. 开发环境：使用`npm run dev`启动开发服务器
2. 生产环境：使用`npm run build`构建静态文件，可部署到任何Web服务器
3. Docker部署：提供Dockerfile配置，支持容器化部署
