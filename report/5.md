## 5. 安装与部署

### 5.1 系统要求

YL-analysis 系统对运行环境有一定的要求，以确保系统能够正常运行和提供良好的性能。以下是详细的系统要求：

#### 5.1.1 硬件要求

- **CPU**: 至少 2 核心，推荐 4 核心或更高
- **内存**: 至少 4GB RAM，推荐 8GB 或更高（尤其是在处理大型代码库时）
- **存储**: 至少 2GB 可用空间，用于存储系统文件、项目文件和分析结果
- **网络**: 稳定的互联网连接，用于 LLM API 调用（如使用 OpenAI API）

#### 5.1.2 软件要求

- **操作系统**: 
  - Windows 10/11
  - macOS 10.15+
  - Ubuntu 20.04+/Debian 10+/CentOS 8+
- **Python**: 3.8 或更高版本
- **Node.js**: 14.0 或更高版本（仅在需要修改前端代码时需要）
- **包管理器**: pip, uv (推荐)

### 5.2 安装步骤

YL-analysis 系统的安装过程相对简单，主要包括获取代码、安装依赖和配置环境等步骤。以下是详细的安装指南：

#### 5.2.1 获取代码

首先，需要从代码仓库获取 YL-analysis 的源代码。可以通过 Git 克隆或直接下载压缩包的方式获取。

```bash
# 使用 Git 克隆代码仓库
git clone <repository-url>
cd YL-analysis
```

#### 5.2.2 安装后端依赖

YL-analysis 后端基于 Python 开发，需要安装相关的 Python 依赖包。推荐使用 uv 包管理器，它比传统的 pip 更快、更可靠。

##### 使用 uv (推荐)

[uv](https://github.com/astral-sh/uv) 是一个快速的 Python 包管理器，可以显著提高依赖安装速度。

```bash
# 安装 uv
pip install uv

# 使用 uv 安装依赖
uv pip install -r requirements.txt
```

##### 使用 pip

如果不想使用 uv，也可以使用传统的 pip 安装依赖。

```bash
pip install -r requirements.txt
```

#### 5.2.3 前端文件

YL-analysis 的构建后前端文件已经包含在 `front/` 目录中，因此通常不需要单独安装和构建前端。如果需要修改前端代码，请参考前端仓库的说明。

### 5.3 启动应用

安装完成后，可以通过以下命令启动 YL-analysis 应用：

#### 5.3.1 使用 uv 启动

如果使用 uv 安装了依赖，需要使用以下命令启动服务器：

```bash
uv run server.py
```

#### 5.3.2 使用 python 启动

如果使用 pip 安装了依赖，需要使用以下命令启动服务器：

```bash
python server.py
```

默认情况下，应用将在 `http://localhost:5000` 上运行。可以通过浏览器访问该地址来使用 YL-analysis 系统。

### 5.4 配置选项

YL-analysis 提供了多种配置选项，可以通过命令行参数或配置文件进行设置。

#### 5.4.1 命令行参数

启动服务器时可以使用以下命令行参数：

```bash
python server.py --host 0.0.0.0 --port 8080 --log-level info
```

| 参数 | 描述 | 默认值 |
|------|------|--------|
| `--host` | 监听地址 | `127.0.0.1` |
| `--port` | 监听端口 | `8080` |
| `--log-level` | 日志级别 (debug, info, warning, error, critical) | `info` |

#### 5.4.2 系统设置

除了命令行参数外，YL-analysis 还提供了通过 Web 界面进行系统设置的功能。在系统运行后，可以通过访问「设置」页面进行配置，包括：

- LLM 服务设置（API 密钥、基础 URL、模型名称等）
- 分析参数设置（超时时间、重试次数等）
- 其他系统参数

这些设置将保存在系统的配置文件中，重启应用后仍然有效。

### 5.5 目录结构

安装完成后，YL-analysis 的目录结构如下：

```
YL-analysis/
├── src/                  # 源代码目录
│   ├── api/              # 后端 API 代码
│   │   ├── ...          # API 相关模块
│   ├── libs/             # 主要业务逻辑库
│   │   ├── ...          # 核心功能模块
├── front/                # 前端文件
│   ├── ...              # 构建后的前端文件
├── challenges/           # 项目目录，存储上传的项目
├── results/              # 结果目录，存储分析结果
├── .venv                 # 虚拟环境（如果使用）
├── requirements.txt      # 依赖列表
├── server.py             # 服务器入口
└── README.md             # 项目说明
```

### 5.6 常见问题解决

在安装和使用 YL-analysis 系统过程中，可能会遇到一些常见问题。以下是一些常见问题及其解决方案：

#### 5.6.1 LLM API 连接问题

**问题**: 无法连接到 LLM API 服务。

**解决方案**:
- 检查 API 密钥是否正确设置
- 检查网络连接是否正常
- 检查 API 服务是否可用
- 尝试使用代理服务器

#### 5.6.2 依赖安装问题

**问题**: 安装依赖时出现错误。

**解决方案**:
- 确保 Python 版本符合要求（3.8+）
- 尝试使用 uv 代替 pip 安装依赖
- 检查是否有网络限制或防火墙问题
- 尝试使用国内镜像源

#### 5.6.3 端口占用问题

**问题**: 启动服务器时提示端口已被占用。

**解决方案**:
- 使用不同的端口启动服务器：`python server.py --port 8081`
- 找到并关闭占用端口的进程

#### 5.6.4 文件权限问题

**问题**: 无法创建或访问项目目录或结果目录。

**解决方案**:
- 确保运行服务器的用户有足够的权限
- 手动创建必要的目录并设置适当的权限

### 5.7 升级指南

当 YL-analysis 发布新版本时，可以按照以下步骤进行升级：

1. 备份重要数据，包括项目文件、分析结果和自定义配置
2. 获取新版本的代码（通过 Git 拉取或下载新版本）
3. 安装新的依赖（如果有）：`uv pip install -r requirements.txt`
4. 启动新版本的应用
5. 验证系统功能是否正常

### 5.8 部署建议

对于生产环境部署，建议考虑以下几点：

1. **使用反向代理**：使用 Nginx 或 Apache 作为反向代理，提供 HTTPS 支持和负载均衡
2. **配置防火墙**：限制对服务器的访问，只允许必要的端口和 IP
3. **定期备份**：定期备份重要数据，防止数据丢失
4. **监控系统**：设置系统监控，及时发现和解决问题
5. **资源隔离**：考虑使用容器（如 Docker）或虚拟环境隔离应用，提高安全性和可维护性
